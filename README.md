# Documentación pública

## Política de privacidad

El archivo `privacy-policy.html` es una página HTML estática, bilingüe (español e inglés), lista para alojar en cualquier hosting HTTPS.

### Antes de publicar

1. Publicar `privacy-policy.html` en una URL HTTPS accesible públicamente.
2. Copiar esa URL HTTPS en `AppLinks.PRIVACY_POLICY_URL` dentro del código de Android.
3. Usar la misma URL en Google Play Console.
4. Revisar la política nuevamente si cambian SDKs o el tratamiento de datos (por ejemplo, al integrar Google Mobile Ads u otros proveedores).

El email de contacto publicado en la política es `loanboxd@proton.me`.
